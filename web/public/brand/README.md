# MacFax Brand Assets

This folder contains the MacFax brand assets for the website.

## Required Files

Please add the following files to this folder:

- **macfax-logo.png** - Wide wordmark logo (for desktop navbar)
- **macfax-mark-512.png** - Square mark logo at 512x512px
- **macfax-mark-180.png** - Square mark logo at 180x180px (for mobile navbar)
- **macfax-mark-32.png** - Square mark logo at 32x32px (for favicon)

## Usage

- Desktop navbar: uses `macfax-logo.png`
- Mobile navbar: uses `macfax-mark-180.png`
- Favicon: uses `macfax-mark-32.png`
